# **Korgi Gaming Portal 🎮**  

A gaming platform where users can explore, play, and manage their favorite games. The platform includes **daily rewards, user profiles, game categories, and an admin panel** for game management.  

## **Features 🚀**  

- **User Authentication** (Firebase Auth)  
- **Daily Rewards System** with Streak Tracking  
- **Favorite & Recently Played Games**  
- **Admin Panel** for Game & User Management  
- **Fully Responsive UI** with Dark Mode  
- **Secure Firestore Database Integration**  

## **Tech Stack 🛠**  

- **Frontend:** React, Tailwind CSS, Framer Motion  
- **Backend:** Firebase Firestore, Firebase Functions  
- **Authentication:** Firebase Auth  
- **State Management:** React Context API
